Unicode ↔ semantic vowel codec.

The only source of truth mapping precomposed Vietnamese vowel characters to the semantic Vowel model and back.

§Zero static data

This module keeps no lookup tables, no arrays, no hash maps, and no heap allocations: every character is decoded and encoded by pure ALU operations (additions, shifts, bitwise AND/OR, constant comparisons). The STEMS/UPPER_STEMS matrices are gone; the codepoint of (base, shape, tone, case) is computed directly from Unicode’s block allocations.

Functions§

decode_vowel
Decodes a precomposed Vietnamese vowel character into its semantic Vowel; None for characters outside the vowel alphabet (a ă â e ê i o ô ơ u ư y with tones, đ, ASCII, …).
encode_vowel
Encodes a semantic Vowel into its single precomposed character, preserving its case; None when the vowel cannot be represented (e.g. Shape::Stroke, which is a consonant transformation).
