pub fn encode_vowel(vowel: Vowel) -> Option<char>
Expand description

Encodes a semantic Vowel into its single precomposed character, preserving its case; None when the vowel cannot be represented (e.g. Shape::Stroke, which is a consonant transformation).

The code point is computed arithmetically from (BaseVowel, Shape, Tone, Case) — no STEMS matrix is consulted. Case is a single subtraction: ASCII/Latin-1 uppercase is the lowercase minus the 0x20 bit, and the block / Extended pairs are even/odd neighbours (lowercase − 1).
