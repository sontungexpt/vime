Frontend-independent Vietnamese input method engine.

Architecture:

Input → Interpreter → Operation → Processor → Unicode
  • character: semantic Vietnamese vowels (base, shape, tone) and the decode_vowel/encode_vowel codec over precomposed characters.
  • Interpreter: turns a key plus interpreter::KeyContext into an Operation, per input-method configuration (ConfiguredInterpreter).
  • Operation: the semantic model of a keystroke.
  • Processor: Vietnamese rules; applies operations to semantic vowels, and parses/renders canonical ASCII syllables into Vietnamese text.
  • Composition + Engine: raw composition, cursor editing, and the frontend-facing state machine.
